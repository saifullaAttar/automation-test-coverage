📝 Write a Component Test — Quick Start

For developers new to writing tests in mumzworld-nextjs

  1. Create ComponentName.test.tsx next to the component
  2. Import: import { render, screen } from '@testing-library/react'
  3. Mock: vi.mock('next-intl', ...) and any hooks
  4. Render: render(<Component prop="value" />)
  5. Assert: expect(screen.getByText('...')).toBeInTheDocument()
  6. Run: npm test -w apps/checkout -- YourFile.test.tsx
→ See example: If.test.tsx

Heavy top = slow feedback, high cost, flaky results.

🎯 The Plan: Flip the Pyramid

Goal: Reduce E2E tests from 200+ down to 15-20 critical flows on both Web and App.

These 15-20 E2E tests become the last gate of quality — run only after component + integration tests pass.

Everything else gets covered faster, cheaper, and more reliably by component + integration tests at the PR level.
